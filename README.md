Projeto Java que simula o sistema de uma biblioteca, onde terá como:

- Cadastrar livros.
- Listar todos os livros.
- Buscar um livro pelo título.
- Emprestar um livro.
- Devolver um livro.
- Mostrar quais livros estão disponíveis e quais estão emprestados.
- Sair do programa.

Com o principal intuito de treinar habilidades em java e desenvolver portifólio
